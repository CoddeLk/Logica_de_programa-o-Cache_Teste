# 💻 Registro de DEV

Um script simples e interativo em **Python** desenvolvido para praticar os fundamentos da lógica de programação, manipulação de entrada de dados (`input`) e formatação de strings (`f-strings`).

## 🚀 O que o script faz?
O programa interage diretamente com o usuário no terminal, coletando informações essenciais de perfil de desenvolvedor e gerando um **crachá DEV** personalizado e estilizado.

Informações coletadas:
- Nome
- Idade
- Linguagem de programação favorita
- Emoji representativo

## 🛠️ Tecnologias Utilizadas
- **Python 3**

## ⚙️ Como Executar o Projeto

1. Certifique-se de ter o Python instalado na sua máquina.
2. Clone este repositório ou baixe o arquivo com o código.
3. Abra o terminal na pasta do projeto e execute:

```bash
python seu_arquivo.py
